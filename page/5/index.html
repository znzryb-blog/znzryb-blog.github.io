思路讲解

一句话

两凸多边形最近距离 = 旋转卡壳 + facing 弧双指针 O(N+M)O(N + M)O(N+M) ；推进准则用「cross(a, b') 角度差」、不要用「dis2 < dis1 顶点-边距离单峰」（贪心在背面弧会卡住）；最终结果必须 (A, B) 和 (B, A) 各调一次取 min⁡\minmin 才覆盖完整。

把最近距离归并到「顶点 → 线段」

facing 弧 + 单调推进

固定 AAA 上一个顶点 ppp ，凸性下 BBB 上「真正可能成为离 ppp 最近的那条边」有且仅有一条 —— 称它为 ppp 的 facing edge。形象点：从 ppp 看过去， BBB 朝向 ppp 那半弧上正对 ppp 的那条边，其它边要么被它挡住、要么转到背面去了。

把 ppp 沿 AAA 走 CCW 一圈，那条 facing 边在 BBB 上的位置是**「短程单调、长程往返」**：

  • 短程（ ppp 走在 AAA 朝 BBB 那半弧上）：facing 边在 BBB 上 单调推进（不回退）

  • 长程（ ppp 越过 AAA 的背面弧）： BBB 没有新边可选，facing 边只能沿同一段 facing 弧 退回来

  • 整圈轨迹 = 「推过去 → 退回来」 = 往返

算法直接好处：两个指针不需要走完一整圈，各自只走完自己的 facing 弧就够了，总步数 ≤N+M\le N + M≤N+M 。

初始 facing pair：A 最低 + B 最高

按代码取：

  • eA\texttt{eA}eA = AAA 上 yyy 最小的点的下标

  • eB\texttt{eB}eB = BBB 上 yyy 最大的点的下标

几何上 eA\texttt{eA}eA 看上去就是 eB\texttt{eB}eB 、 eB\texttt{eB}eB 看下去就是 eA\texttt{eA}eA —— 这一对是初始 facing pair，也是 AAA / BBB 各自 facing 弧的一个端点。

不过这个初始只在「 BBB 整体在 AAA 上方」时直观对齐；其它分布下（ AAA 在右、 BBB 在左之类）yMnA + yMxB 不一定是真 facing pair。没关系 —— 推进准则用 cross 角度差驱动后，初始位置不正确也能在 O(N+M)O(N + M)O(N+M) 步内追上正确的对踵 pair，所以这个朴素初始化就够了。

设：

  • a⃗=Ai+1−Ai\vec{a} = A_{i+1} - A_ia=Ai+1​−Ai​ ： AAA 在 AiA_iAi​ 的 CCW 出边方向

  • b⃗′=Bj−Bj+1\vec{b}' = B_j - B_{j+1}b′=Bj​−Bj+1​ ： BBB 在 BjB_jBj​ 的 CCW 出边 反向（因为 BBB 的 facing 弧逆 BBB 的 CCW 序前进）

几何意义：初始 facing pair 处 a⃗\vec{a}a 和 b⃗′\vec{b}'b′ 都大约朝 +x+x+x ，几乎平行同向；两者沿各自多边形 CCW 推进时都向 CCW 方向旋转（凸性）。 cross(a⃗, b⃗′)\mathrm{cross}(\vec{a},\ \vec{b}')cross(a, b′) 衡量两者角度差：

  • >0> 0>0 ： b⃗′\vec{b}'b′ 在 a⃗\vec{a}a 的 CCW 一侧 ⇒\Rightarrow⇒ a⃗\vec{a}a 角度落后 ⇒\Rightarrow⇒ 让 AAA 推一步追上

  • <0< 0<0 ：反之，让 BBB 推一步

为什么这样不会 TLE：每步刚好推一个指针、各自只能 forward。 iii 走完 AAA 一圈、 jjj 走完 BBB 一圈就停，总步数 ≤N+M\le N + M≤N+M 。背面弧问题自动消失 —— cross 一直按角度差驱动，根本不依赖「dis 谁更小」这种局部贪心。

为什么必须 (A, B) + (B, A) 各调一次

单次 cal_min_dis_two_convex(A, B) 只覆盖**「 AAA 顶点 → BBB 边」**这组对偶配置 —— 也就是「枚举 AAA 上每个顶点，找 BBB 上对应的 facing 边」。

但反对称几何里答案可能取在另一边：细长 AAA 戳向粗 BBB 的边中间， AAA 的端点垂足落在 BBB 的边内部 —— 这种「 AAA 顶点 - BBB 边」抓得到；反过来「 BBB 顶点 - AAA 边」抓不到。

解决：把同一份代码以 (B, A) 参数顺序再跑一遍，补上反向对偶，最后两次取 min⁡\minmin ：

`c++

DB ans = INFINITY;

ans = min(ans, cal_min_dis_two_convex(A, B));

ans = min(ans, cal_min_dis_two_convex(B, A));

// 两凸多边形最近距离（旋转卡壳, O(n + m)）

// 单次调用只覆盖「A 边 → B 顶点」配置，

// 调用方需以 (A, B) 和 (B, A) 各调一次取 min。

template

DB cal_min_dis_two_convex(vector<Point> A, vector<Point> B) {

reorder_polygon(A);

reorder_polygon(B);

ll yMnA = min_element(all(A), [](const Point<T> &a, const Point<T> &b) {

    return a.y < b.y;

}) - A.begin();

ll yMxB = max_element(all(B), [](const Point<T> &a, const Point<T> &b) {

    return a.y < b.y;

}) - B.begin();

DB ans = INFINITY;

ll eA = yMnA, eB = yMxB;

for (int _ = 0; _ < SZ(A) + SZ(B); ++_) {

    auto check = [&]() {

        auto vecA = A[(eA + 1) % SZ(A)] - A[eA];

        auto vecB = B[(eB + 1) % SZ(B)] - B[eB];

        return cross(vecA, vecB) > 0;

    };

    while (check()) ++eB, eB %= SZ(B);

    ans = min(ans, distanceSS(Line(A[(eA + 1) % SZ(A)], A[eA]),

                              Line(B[(eB + 1) % SZ(B)], B[eB])));

    eA = (eA + 1) % SZ(A);

}

return ans;

}
