ABC-470-E - Concentration （翻牌配对）

Posted on 2026-08-10

题目大意

翻牌配对

时限 2000 ms，内存 1024 MB。

给定整数 N,LN, LN,L 以及 NNN 个两两不同的整数 A1,A2,…,ANA_1, A_2, \dots, A_NA1​,A2​,…,AN​。

桌上共有 2N2N2N 张牌，每个数值 AiA_iAi​ 恰好写在其中两张牌的正面上，牌的背面没有任何信息。

初始时把所有牌随机洗乱后背面朝上摆放。等价地说：设 BBB 是把序列 (A1,A1,A2,A2,…,AN,AN)(A_1, A_1, A_2, A_2, \dots, A_N, A_N)(A1​,A1​,A2​,A2​,…,AN​,AN​) 均匀随机打乱后得到的长度为 2N2N2N 的序列，则第 iii 张牌正面的数字为 BiB_iBi​。

玩家知道所有的 AiA_iAi​，但最初不知道任何 BiB_iBi​。一旦某张牌 iii 被翻开，玩家就会永久记住 BiB_iBi​ 的值。

游戏开始时，生命值为 LLL，得分为 000，尚未被移除的牌的下标集合为 S={1,2,…,2N}S = \{1, 2, \dots, 2N\}S={1,2,…,2N}。玩家在任何时刻都知道当前的生命值、得分和集合 SSS。

重复执行以下步骤，直到生命值变为 000 或者 SSS 为空：

  1. 玩家根据当前已知信息，从 SSS 中选择一张牌 iii 并翻开，获知 BiB_iBi​。

  2. 玩家根据当前已知信息（包括刚获知的 BiB_iBi​），从 S∖{i}S \setminus \{i\}S∖{i} 中选择一张牌 jjj 并翻开，获知 BjB_jBj​。

  3. 若 Bi=BjB_i = B_jBi​=Bj​，则把 i,ji, ji,j 从 SSS 中移除，并把得分增加 BiB_iBi​。

  4. 若 Bi≠BjB_i \neq B_jBi​=Bj​，则把这两张牌翻回背面，并把生命值减少 111。

玩家以最大化最终得分的期望值为目标采取最优策略。请求出游戏结束时的期望得分。

输入从标准输入按以下格式给出：

第一行两个整数 NNN 和 LLL。

第二行 NNN 个整数 A1,A2,…,ANA_1, A_2, \dots, A_NA1​,A2​,…,AN​。

输出一行一个实数，表示最优策略下游戏结束时的期望得分。答案与标准答案的绝对误差或相对误差不超过 10−510^{-5}10−5 即视为正确。

  • 1≤N≤2001 \leq N \leq 2001≤N≤200

  • 1≤L≤2001 \leq L \leq 2001≤L≤200

  • 1≤A1<A2<⋯<AN≤1051 \leq A_1 < A_2 < \dots < A_N \leq 10^51≤A1​<A2​<⋯<AN​≤105

  • 所有输入值均为整数。

游戏可能按如下方式进行。为了区分这六张牌，分别称它们为 A、B、C、D、E、F。

游戏以生命值 222、得分 000 开始。

翻开卡牌 A，上面写着 333。
翻开卡牌 B，上面写着 222。
因为数字不同，把两张牌翻回背面，生命值减少 111，变为 111。

翻开卡牌 C，上面写着 333。
翻开卡牌 A，上面写着 333。
因为数字相同，把这两张牌移出桌面，得分增加 333，变为 333。

翻开卡牌 D，上面写着 111。
翻开卡牌 E，上面写着 222。
因为数字不同，把两张牌翻回背面，生命值减少 111，变为 000。

生命值变为 000，游戏结束，最终得分为 333。

注意，在上述过程中刚翻开卡牌 C 之后，玩家可以利用「卡牌 C 正面写着 333」这一信息，选择翻开另一张已经知道写着 333 的卡牌 A。
