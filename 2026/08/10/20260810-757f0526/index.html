关于按位异或
非负整数 A,BA,BA,B 的按位异或 A⊕BA \oplus BA⊕B 定义如下：A⊕BA \oplus BA⊕B 在二进制表示下 2k2^k2k（k≥0k \geq 0k≥0）位上的数字，当 A,BA,BA,B 在二进制表示下 2k2^k2k 位上的数字恰有一个为 111 时为 111，否则为 000。
例如 3⊕5=63 \oplus 5 = 63⊕5=6（二进制表示为 011⊕101=110011 \oplus 101 = 110011⊕101=110）。
一般地，kkk 个非负整数 p1,p2,…,pkp_1,p_2,\ldots,p_kp1​,p2​,…,pk​ 的按位异或定义为 (…((p1⊕p2)⊕p3)⊕⋯⊕pk)(\dots((p_1 \oplus p_2) \oplus p_3) \oplus \dots \oplus p_k)(…((p1​⊕p2​)⊕p3​)⊕⋯⊕pk​)，可以证明其结果与 p1,p2,…,pkp_1,p_2,\ldots,p_kp1​,p2​,…,pk​ 的顺序无关。
