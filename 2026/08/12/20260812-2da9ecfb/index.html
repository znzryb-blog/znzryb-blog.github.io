题目大意

唯首是瞻

时间限制：C/C++/Rust/Pascal 1 秒，其他语言 2 秒
空间限制：C/C++/Rust/Pascal 1024 MB，其他语言 2048 MB
Special Judge，64bit IO Format: %lld

在莫扎瑞拉的魔法国度里，一场召唤仪式出了大岔子。布朗尼本想召唤传说中的女法师加莱特完整降临，结果只有她的一颗头颅现身了。这颗漂浮的头颅却毫不在意，宣称道：“有头就够了！我要证明，光凭我的头脑就胜过你们的整副身躯。”

为了展示自己的智力，加莱特放出豪言：

“随便拿两个正整数来。只要你告诉我其中一个数的前 aaa 位、另一个数的前 bbb 位，我就能万无一失地说出它们乘积的前 ccc 位。那些看不见的低位，就像身体对于天才一样无关紧要。”

学院里最敏锐的数学家奥兰洁特立刻察觉到了其中的漏洞。但仅仅指出谬误还不够，加莱特要求给出一个具体的反例：“你要真这么聪明，就找出两对数来：它们的前几位分别相同，乘积的前几位却不同！”

奥兰洁特一时之间构造不出这样的例子，于是她来向你求助。

形式化地说，给定三个正整数 aaa、bbb、ccc，请构造两对正整数 (x1,y1)(x_1, y_1)(x1​,y1​) 与 (x2,y2)(x_2, y_2)(x2​,y2​)，满足以下条件：

  • 在通常的十进制表示下（无前导零），x1x_1x1​ 与 x2x_2x2​ 都至少有 aaa 位，且二者的前 aaa 位完全相同；

  • 同样地，y1y_1y1​ 与 y2y_2y2​ 都至少有 bbb 位，且二者的前 bbb 位完全相同；

  • 乘积 x1⋅y1x_1 \cdot y_1x1​⋅y1​ 与 x2⋅y2x_2 \cdot y_2x2​⋅y2​ 都至少有 ccc 位，但二者的前 ccc 位不同。

每个测试点仅一行，包含三个整数 aaa、bbb、ccc（1≤a,b≤1051 \le a, b \le 10^51≤a,b≤105，1≤c<a+b−11 \le c < a + b - 11≤c<a+b−1）。

输出四个整数 x1x_1x1​、y1y_1y1​、x2x_2x2​、y2y_2y2​，满足

10a−1≤x1,x2<105⋅105,10b−1≤y1,y2<105⋅10510^{a-1} \le x_1, x_2 < 10^{5 \cdot 10^5}, \qquad 10^{b-1} \le y_1, y_2 < 10^{5 \cdot 10^5} 10a−1≤x1​,x2​<105⋅105,10b−1≤y1​,y2​<105⋅105

且符合题目要求。这些整数均不能含有前导零。可以证明在给定约束下解总是存在的。

x1=1704x_1 = 1704x1​=1704 与 x2=1789x_2 = 1789x2​=1789 的前 222 位均为 171717；y1=1313y_1 = 1313y1​=1313 与 y2=1346y_2 = 1346y2​=1346 的前 222 位均为 131313。

而 1704×1313=22373521704 \times 1313 = 22373521704×1313=2237352，其前 222 位为 222222；1789×1346=24079941789 \times 1346 = 24079941789×1346=2407994，其前 222 位为 242424。两者的前 222 位不同，因此这是一组合法的构造。

固定住 xxx 的前 aaa 位之后，xxx 还剩多大的活动余地？把它量化出来。
答
xxx 只能写成 A⋅10t+rA\cdot 10^{t}+rA⋅10t+r（0≤r<10t0\le r<10^t0≤r<10t），即它的尾数被锁死在 [A, A+1)[A,\,A+1)[A,A+1) 内，相对活动幅度至多 1A≤10−(a−1)\frac1A\le 10^{-(a-1)}A1​≤10−(a−1)。yyy 同理。于是乘积的尾数活动幅度只有 101−a+101−b10^{1-a}+10^{1-b}101−a+101−b 量级。靠低位微调去顶动第 ccc 位是完全没希望的，尤其当 c=1c=1c=1 而 a,ba,ba,b 很大时。

想通过改变数字的后缀（低位）来影响乘积的最高 ccc 位，必须利用什么机制？

答：必须利用连锁进位机制。当高位部分的乘积处于进位的临界状态（如形如 999…9999\dots9999…9 ）时，低位产生的微小增量才能不断向高位触发进位，进而使得最高位发生突变。为了制造上述的“进位临界状态”，两数的前缀 XXX 和 YYY 应该构造成什么形式？

为了制造上述的**“进位临界状态”**，两数的前缀 XXX 和 YYY 应该构造成什么形式？

答：需要让 X×YX \times YX×Y 的结果尽可能呈现一连串的 999。一种极简的构造是令 X=10a−1X = 10^{a-1}X=10a−1（100..00100..00100..00，长度为 a），且 Y=10b−1Y = 10^b - 1Y=10b−1（999...999999...999999...999，长度为这个这个 b）。此时 X×Y=10a+b−1−10a−1X \times Y = 10^{a+b-1} - 10^{a-1}X×Y=10a+b−1−10a−1，其结果形如 99…900…099\dots900\dots099…900…0，恰好为连锁进位创造了绝佳条件。

确定了前缀后，两对数字 (x1,y1)(x_1, y_1)(x1​,y1​) 和 (x2,y2)(x_2, y_2)(x2​,y2​) 的后缀应如何选取，才能确保乘积的前 ccc 位一定不同？

答：将第一组数字的后缀全部填充为 000，此时乘积没有任何来自低位的增量，最高位保持为 999；将第二组数字的后缀全部填充为 999（即增量最大化），乘积加上这部分增量后会越过进位临界点，使得最高位进位变成 111。由于 c<a+b−1c < a+b-1c<a+b−1，前 ccc 位必定会因此改变。
