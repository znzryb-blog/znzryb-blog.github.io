ABC-468-F - Chmax（观察到每步操作都要做只能够说有的时候不生效，然后就可以发现，有的是数字，我们是必须去取的）

题目大意

题目描述

给定正整数 NNN 和 (1,2,…,N)(1,2,\ldots,N)(1,2,…,N) 的一个排列 P=(P1,P2,…,PN)P=(P_1,P_2,\ldots,P_N)P=(P1​,P2​,…,PN​)。

有三个变量 x,y,cx,y,cx,y,c，初始时 x=y=c=0x=y=c=0x=y=c=0。

你需要按 k=1,2,…,Nk=1,2,\ldots,Nk=1,2,…,N 的顺序，依次执行下列两种操作之一：

  • 操作 111：若 x<Pkx < P_kx<Pk​，则将 ccc 增加 111；随后将 xxx 替换为 max⁡(x,Pk)\max(x,P_k)max(x,Pk​)。

  • 操作 222：若 y<Pky < P_ky<Pk​，则将 ccc 增加 111；随后将 yyy 替换为 max⁡(y,Pk)\max(y,P_k)max(y,Pk​)。

求最终 ccc 的最大可能值。

输入格式

输入从标准输入以如下格式给出：

NN N

P1 P2 … PNP_1\ P_2\ \ldots\ P_N P1​ P2​ … PN​

输出格式

输出一行一个整数，表示答案。

数据范围

  • 1≤N≤5×1051\le N\le 5\times 10^51≤N≤5×105

  • PPP 是 (1,2,…,N)(1,2,\ldots,N)(1,2,…,N) 的一个排列

  • 输入的所有值均为整数

样例

按如下方式操作可以达到 c=4c=4c=4：

  • k=1k=1k=1 时：执行操作 111，此时 (x,y,c)=(4,0,1)(x,y,c)=(4,0,1)(x,y,c)=(4,0,1)。

  • k=2k=2k=2 时：执行操作 111，此时 (x,y,c)=(4,0,1)(x,y,c)=(4,0,1)(x,y,c)=(4,0,1)。

  • k=3k=3k=3 时：执行操作 222，此时 (x,y,c)=(4,1,2)(x,y,c)=(4,1,2)(x,y,c)=(4,1,2)。

  • k=4k=4k=4 时：执行操作 222，此时 (x,y,c)=(4,2,3)(x,y,c)=(4,2,3)(x,y,c)=(4,2,3)。

  • k=5k=5k=5 时：执行操作 222，此时 (x,y,c)=(4,5,4)(x,y,c)=(4,5,4)(x,y,c)=(4,5,4)。

无论如何操作都无法使 ccc 超过 444，因此输出 444。
