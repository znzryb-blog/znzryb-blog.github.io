Gym 105158 D - 距离之比

Posted on 2026-05-15

原题：Gym 105158 D 距离之比 ｜ vjudge

AC：vjudge solution 69896828

题目大意

平面上 nnn 个互不重合的点 P1,…,PnP_1, \dots, P_nP1​,…,Pn​ ，求

max⁡1≤i<j≤ndis1(Pi,Pj)dis2(Pi,Pj)\max_{1 \le i < j \le n} \frac{\mathrm{dis1}(P_i, P_j)}{\mathrm{dis2}(P_i, P_j)} 1≤i<j≤nmax​dis2(Pi​,Pj​)dis1(Pi​,Pj​)​

其中 dis1\mathrm{dis1}dis1 是曼哈顿距离 ∣xi−xj∣+∣yi−yj∣|x_i - x_j| + |y_i - y_j|∣xi​−xj​∣+∣yi​−yj​∣ ， dis2\mathrm{dis2}dis2 是欧几里得距离 (xi−xj)2+(yi−yj)2\sqrt{(x_i - x_j)^2 + (y_i - y_j)^2}(xi​−xj​)2+(yi​−yj​)2​ 。

数据范围

  • 1≤T≤1051 \le T \le 10^51≤T≤105 组数据

  • 2≤n≤2×1052 \le n \le 2 \times 10^52≤n≤2×105 ， ∑n≤2×105\sum n \le 2 \times 10^5∑n≤2×105

  • ∣xi∣,∣yi∣≤109|x_i|, |y_i| \le 10^9∣xi​∣,∣yi​∣≤109

  • 输出绝对/相对误差 ≤10−9\le 10^{-9}≤10−9 即可

思路讲解

一句话

比值 dis1/dis2\mathrm{dis1} / \mathrm{dis2}dis1/dis2 只取决于两点连线的方向角， ±45∘\pm 45^\circ±45∘ 方向最大 2\sqrt{2}2​ 、坐标轴方向最小 111 。所以题目等价于"找方向最接近 ±45∘\pm 45^\circ±45∘ 的点对"。一个中值不等式引理把它直接砍到 O(nlog⁡n)O(n \log n)O(nlogn) ：按 x+yx + yx+y 排序扫相邻、再按 x−yx - yx−y 排序扫相邻就完事。

第 1 步：比值只取决于方向

设 θ\thetaθ 是 PiPj→\overrightarrow{P_i P_j}Pi​Pj​​ 与 xxx 轴的夹角。把 dis2\mathrm{dis2}dis2 当分母提出来：

dis1dis2=∣cos⁡θ∣+∣sin⁡θ∣=2sin⁡ ⁣(∣θ′∣+π4)\frac{\mathrm{dis1}}{\mathrm{dis2}} = |\cos\theta| + |\sin\theta| = \sqrt{2}\sin\!\left(|\theta'| + \tfrac{\pi}{4}\right) dis2dis1​=∣cosθ∣+∣sinθ∣=2​sin(∣θ′∣+4π​)

折叠到一个象限后看，整个比值是关于 θ\thetaθ 的纯三角函数——也就是跟两点距离绝对长度无关、只看方向。

关键不变量： θ\thetaθ 越接近 ±45∘\pm 45^\circ±45∘ 或 ±135∘\pm 135^\circ±135∘ ，比值越大；极大值 2≈1.4142\sqrt{2} \approx 1.41422​≈1.4142 ； θ=0\theta = 0θ=0 或 π/2\pi/2π/2 时退化为 111 。

第 2 步：旋转到 (u, v) 化为 Chebyshev

做仿射变换

u=x+y,v=x−yu = x + y, \qquad v = x - y u=x+y,v=x−y

也就是把 xyxyxy 平面旋转 −45∘-45^\circ−45∘ 再放缩 2\sqrt{2}2​ 。神奇的事情发生了—— L1L^1L1 距离变成了 Chebyshev 距离：

dis1=max⁡(∣Δu∣,∣Δv∣),dis2=Δu2+Δv22\mathrm{dis1} = \max(|\Delta u|, |\Delta v|), \qquad \mathrm{dis2} = \sqrt{\frac{\Delta u^2 + \Delta v^2}{2}} dis1=max(∣Δu∣,∣Δv∣),dis2=2Δu2+Δv2​​

原 ±45∘\pm 45^\circ±45∘ 方向在 (u,v)(u, v)(u,v) 平面变成 uuu 轴 / vvv 轴方向。代入比值：

dis1dis2=2⋅max⁡(∣Δu∣,∣Δv∣)Δu2+Δv2\frac{\mathrm{dis1}}{\mathrm{dis2}} = \sqrt{2} \cdot \frac{\max(|\Delta u|, |\Delta v|)}{\sqrt{\Delta u^2 + \Delta v^2}} dis2dis1​=2​⋅Δu2+Δv2​max(∣Δu∣,∣Δv∣)​

不妨设 ∣Δu∣≥∣Δv∣|\Delta u| \ge |\Delta v|∣Δu∣≥∣Δv∣ ，记 t=∣Δv∣/∣Δu∣∈[0,1]t = |\Delta v| / |\Delta u| \in [0, 1]t=∣Δv∣/∣Δu∣∈[0,1] ，比值化为 2/1+t2\sqrt{2} / \sqrt{1 + t^2}2​/1+t2​ ——单调地越接近某根坐标轴（ t→0t \to 0t→0 ）越大。

问题转化：在 (u,v)(u, v)(u,v) 平面找点对，使其连线方向最接近 uuu 轴或 vvv 轴。

第 3 步：核心引理 — 中值不等式

转化后的问题：找一对点使 ∣(ui−uj)/(vi−vj)∣\left| (u_i - u_j) / (v_i - v_j) \right|∣(ui​−uj​)/(vi​−vj​)∣ 最大（以 vvv 为横轴看"斜率绝对值最大"）。

引理：把点按 vvv 升序排得 v(1)≤v(2)≤⋯≤v(n)v_{(1)} \le v_{(2)} \le \dots \le v_{(n)}v(1)​≤v(2)​≤⋯≤v(n)​ 。最优点对必然出现在相邻位，即存在最优解 (P(k),P(k+1))(P_{(k)}, P_{(k+1)})(P(k)​,P(k+1)​) 。

证明（中值不等式）：取三点 i,k,ji, k, ji,k,j 满足 vi<vk<vjv_i < v_k < v_jvi​<vk​<vj​ 。记 sab=(ub−ua)/(vb−va)s_{ab} = (u_b - u_a) / (v_b - v_a)sab​=(ub​−ua​)/(vb​−va​) 。则

sij=(uk−ui)+(uj−uk)(vk−vi)+(vj−vk)s_{ij} = \frac{(u_k - u_i) + (u_j - u_k)}{(v_k - v_i) + (v_j - v_k)} sij​=(vk​−vi​)+(vj​−vk​)(uk​−ui​)+(uj​−uk​)​

分母两项同号，所以 sijs_{ij}sij​ 是 sik,skjs_{ik}, s_{kj}sik​,skj​ 的加权"中值"：

min⁡(sik,skj)≤sij≤max⁡(sik,skj)\min(s_{ik}, s_{kj}) \le s_{ij} \le \max(s_{ik}, s_{kj}) min(sik​,skj​)≤sij​≤max(sik​,skj​)

故 ∣sij∣≤max⁡(∣sik∣,∣skj∣)|s_{ij}| \le \max(|s_{ik}|, |s_{kj}|)∣sij​∣≤max(∣sik​∣,∣skj​∣) 。

跨过中间点 kkk 的非相邻对，其斜率绝对值不会超过两个跨界子对之一。一路归纳下去，最优解总能退化到 vvv 排序后的相邻对。 □\square□

中值不等式那一招很优美——它说"跨过去更长 ⇒\Rightarrow⇒ 不更陡"，本质上是凸性：把分子分母都看成"长度向量"沿 vvv 轴的累加，斜率永远夹在子段斜率之间。这是一个比凸包/旋转卡壳更对路的工具，专门针对"对所有点对极大化方向相关量"这一类几何题。

第 4 步：完整算法

引理只处理了"方向最接近 uuu 轴"。对称的"方向最接近 vvv 轴"同理——按 uuu 排序扫相邻对就能覆盖。所以：

  1. 按 u=x+yu = x + yu=x+y 升序排，遍历相邻对更新最大比值

  2. 按 v=x−yv = x - yv=x−y 升序排，遍历相邻对更新最大比值

  3. 两次累计的最大值就是答案

两次 sort + 两次 O(n)O(n)O(n) 扫描，单组 O(nlog⁡n)O(n \log n)O(nlogn) 。每对的比值直接用原 (x,y)(x, y)(x,y) 坐标算（无需真把点替换成 (u,v)(u, v)(u,v) ）。

几个实现细节：

  • distancePPL1 返回的是 __int128_t （我新加进几何模板的"曼哈顿距离"），所以 (DB) 强转一次再除浮点，不转的话整数除法直接出 1 全错

  • ∣x∣,∣y∣≤109|x|, |y| \le 10^9∣x∣,∣y∣≤109 ， dx2+dy2≤8×1018dx^2 + dy^2 \le 8 \times 10^{18}dx2+dy2≤8×1018 卡在 long long 上界 9.2×10189.2 \times 10^{18}9.2×1018 内，不会爆 ll。要稳一点 __int128_t 兜底也行

  • 全程用 long double 配 sqrtl 保精度， cout << fixed << setprecision(12) 输出

  • 多组 T≤105T \le 10^5T≤105 ， ios::sync_with_stdio(false) 必须关掉缓冲

心路历程

这道题没什么"卡 WA"的心路——主要是思路推导一条线下来：

  1. 看到 dis1/dis2\mathrm{dis1} / \mathrm{dis2}dis1/dis2 直觉就反应"这跟方向有关"，写成 ∣cos⁡θ∣+∣sin⁡θ∣|\cos\theta| + |\sin\theta|∣cosθ∣+∣sinθ∣ 后就锁死"找最接近 ±45∘\pm 45^\circ±45∘ 方向的点对"

  2. 但是 O(n2)O(n^2)O(n2) 枚举显然不行（ ∑n=2⋅105\sum n = 2 \cdot 10^5∑n=2⋅105 ），第一反应想凸包——结论：凸包做不了。反例：最优对可以在凸包内部。比如三角形 A=(0,0),B=(10,10),C=(10,−10)A = (0, 0), B = (10, 10), C = (10, -10)A=(0,0),B=(10,10),C=(10,−10) 加两个内部点 D=(5,0),E=(5,1)D = (5, 0), E = (5, 1)D=(5,0),E=(5,1) ， D,ED, ED,E 的 Δu=0\Delta u = 0Δu=0 比值直接 2\sqrt{2}2​ 顶天，但 D,ED, ED,E 都不在凸包上

  3. 直接看了官方题解才知道是中值不等式那一招。证明优美但"赛场上能不能想到"是另一回事——下次见到「对所有点对极大化方向相关量」类几何题先把这条工具拿出来用

  4. 实现时本来要在 Solve 里手写 L1 / L2 距离，顺手沉淀进几何模板（这次加了 distancePP / distancePPL1 / distancePPLinf 三个自由函数 + Point::normL1 / normLinf 两个成员），后续题目直接复用

Take-away：「最大化 / 最小化 f(θij)f(\theta_{ij})f(θij​) 」（ θij\theta_{ij}θij​ 是点对方向角）这一类问题，先想"排序 + 邻点扫"配中值不等式，比凸包 / 旋转卡壳更对路。
